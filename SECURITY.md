# Security Policy

## Supported Versions

This repository contains exploratory research materials, terminology, and conceptual threat models. No production code, library, or protocol implementation is distributed in this repository.

| Version | Supported |
| ------- | --------- |
| Research / Concept | :white_check_mark: |

## Reporting a Vulnerability

As this is an exploratory research project with no software implementation, security concerns primarily relate to:
- Flaws in the conceptual threat models or security assumptions.
- Vulnerabilities or attack vectors in theoretical negotiation protocols discussed.
- Errors in cryptographic assumptions (e.g., Silent Payments, Payjoin, etc.).

If you identify a critical flaw in the theoretical framework, threat models, or design scenarios that could impact future implementations:
1. Please open a Git issue using the **Research Feedback** template, or
2. Reach out privately to the maintainer via email: `jaykon4me@gmail.com`

We appreciate rigorous peer review and feedback that helps harden any future proposed designs.
